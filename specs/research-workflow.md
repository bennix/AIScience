# AI 科研工作台 0.1

Electron 本地主进程持有密钥和网络权限，隔离的渲染进程维护研究项目与可见任务，持久化经受限 IPC 原子写入。项目包含研究目标、真实检索文献、会话、证据笔记、CSV 描述统计和研究成果。

流程：假说 → 文献 → 实验方案 → 环境配置 → 数据描述统计 → 报告 → 中英 LaTeX / PDF。用户可独立调用任何阶段。模型不自动执行代码或安装环境；导出的环境配置真实写入磁盘，执行状态明确显示“未运行”。图表只能来自导入数据。

ZenMux 使用指定 Base URL 和两个模型 ID；没有 Key 时仍可管理项目、检索论文、分析 CSV 和导出。Key 由 Electron safeStorage 加密持久化，界面只能读取 hasKey。真实模型请求是否可用需用户配置 Key 后验证。

## 会话引导

参考 Zcode specs/running-guidance.md 和 core/runtime/methods/steering.ts 的语义，独立实现最小版本：
- 生成中提交文字写入同项目的持久化引导队列，显示“等待应用”，不声称已经影响正在输出的模型。
- OpenAI-compatible HTTP 流不支持原地追加用户消息；安全边界为当前请求结束后，用会话历史及新引导发起续轮。
- 每条引导具有稳定 ID 和 pending/applying/applied 状态。重启恢复 applying 为 held，绝不自动请求模型。
- 停止任务保留未消费引导为 held；只有用户显式继续才应用。删除/编辑针对原条目，不重新提交。
- 防止跨项目串流、并发生成、重复引导消费；在持久化成功后才显示接受成功。进行中项目不可切换或删除。

## 验收

无 Key 有明确设置入口；Key 不返回渲染进程；真实科研来源返回可核对 DOI；CSV 缺失值不作零；含中英文/TeX 元字符的内容安全转义；图表数据不由模型编造；停止/续轮状态可见；重启不自动运行研究或历史引导；PDF 禁用 shell escape；导出失败保留明确错误。

## 托管实验环境

主进程 ResearchEnvironment 是运行状态唯一所有者，经 env-status 事件投影到界面。开始时选择本机 Python 3.11，在应用私有 environments/env-* 下创建 venv，安装固定科学计算依赖。Jupyter 绑定 127.0.0.1、使用随机 token，程序生成配置而不是 shell 命令拼接。原始 CSV 以 dataset.csv 写入项目 research-files 目录；此目录在环境回收后保留。回复中的 Python 代码可保存为 Notebook，但不会自动执行。

关闭应用或用户停止时结束托管进程组并删除 venv；断开连接且空闲 15 分钟自动回收，忙碌内核不进入该回收条件。冷启动检查残留 runtime.json，仅在系统进程命令同时匹配托管环境 Python 路径与 Jupyter 时结束残留进程组，防止误杀其他进程。不得称 venv 为操作系统安全沙箱。

## RAG 与接口检测

项目选中文献（元数据/摘要或开放全文）、导入 PDF/文本和研究者笔记是唯一索引语料。固定来源 ID 和字符偏移，片段约 1200 字符、200 重叠，上限 300。索引包含 Embedding 模型身份、语料指纹和文本哈希；未变化片段复用向量。检索使用同模型查询向量与余弦相似度，返回前 6 个证据片段；模型或语料变化必须提示重建。片段和提示中的指令不作为应用操作授权。没有索引或有效凭证时不假装成功，也不默默回退到“RAG”。

每条科研会话可开启 RAG。检索和生成共享主进程活动请求的取消信号，防止停止后继续请求。回答收到片段并附来源 ID，界面保存本轮证据。不将相似度解释为结论可靠度。论文 ID 保持稳定，语义排序只改变展示顺序。

设置页“保存并检测”先加密保存，再向聊天与 embeddings 接口发最小测试请求。分别校验 completion 和向量数量、维度、有限性；保存检测时间和当前模型身份。检测期间设置变化则不把旧结果写为当前成功；Key/模型变化后清除旧检测结果。真实测试依赖用户 Key，不用测试响应宣称线上可用。

## 会话附件

每条普通消息或中途引导最多 6 个附件。支持通过输入框粘贴图像/文件或系统多选上传；单文件最大 20MB，文件文本最大 10 万字符。支持 PNG/JPEG/WebP/GIF、PDF 和 UTF-8 TXT/MD/CSV/JSON/TeX/Python/R/YAML/日志。图像显示本地缩略图，文件显示类型缩略卡，右上角按钮仅移除待发送附件。已发送附件保留在历史中，中途引导持久化引用并在安全边界应用。

原内容保存在应用私有附件目录，项目 JSON 只存缩略图和元信息。主进程验证 ID/数量/类型，不接受任意文件路径；图片统一转换为 JPEG 发送，PDF 提取正文，文本前 20,000 字符进入模型并提示截断。当前附件加历史附件每次最多读取 6 个；历史优先最近消息。附件不会自动加入 RAG。未配置 Key 时不清空草稿附件；粘贴普通文字仍按原有输入处理。

## 报告参考代码、语种与审稿修订

目录由用户显式输入/粘贴、拖入或通过系统选择后登记。主进程保留 canonical 路径注册表，生成时只给当前项目开放注册过的 referenceId。模型只读工具支持分页目录、带行号读取、字面代码搜索；realpath 检查阻止越界，排除常见密钥/凭证和依赖缓存。目录内说明文件仅作为参考数据，不是执行指令。模型工具调用结果进入下一轮上下文并记录实际读取位置。模型拒绝工具协议时返回错误，不声称读过代码。

报告语种采用单一项目 language 字段，报告页和会话选择同步。覆盖 20 种常用语种，模型任务明确写入语种名称。PDF 为非拉丁文字配置本地字体，RTL 语言在 pgfplots/hyperref 之后加载 polyglossia，避免 bidi 加载次序错误。ISO 日期避免语言包生成缺失的数字字形。

审稿修订 mode=revision：上下文包含当前文稿与意见，响应必须是 manuscript / changes 字符串结构。主进程验证格式后返回；UI 保存 revisionDraft，绝不直接覆盖 manuscript。采用时保存 previousManuscript；若生成期间原稿被编辑，采用前提示覆盖冲突。放弃草稿不改原稿；撤回恢复上一稿。重启可恢复审稿意见、草稿和撤回快照。

## 数学联合验证门槛

设置 mathGate 默认开启。AI 生成报告、采用审稿修订、将会话回复用作正文及所有报告导出都经过主进程验证入口。两个不同聊天模型并行独立复核相同候选稿与数据/已核验形式化证据，不给彼此意见。双方均 pass 才认定数学复核通过；双方均 not_applicable 且本地未检测显式数学结构时可认定无需数学复核。fail、uncertain、请求失败、结构错误或分歧一律阻止。模型结果不是形式化证明。

检查记录绑定标题、完整正文、数据摘要、形式化证据和验证模型列表的哈希；修改后不复用旧通过状态。失败候选稿单独保留，不覆盖原稿。导出在主进程再次检查，不能仅靠 renderer 显示的绿标放行。关闭数学门槛是用户的显式设置，UI 标为未进行联合验证，不能称为数学检查通过。无有效 Key 无法完成真实模型复核；如需纯本地排版可明确关闭这一设置。

## 形式化证明

独立于两模型意见的 Lean 4.35.0 受限入口。自然语言问题可由 AI 起草命题候选并给语义解释；用户审阅后冻结单行 Lean 陈述。冻结快照由主进程登记；AI 只能生成/修复 by 证明体。候选拒绝 sorry/admit、新公理、命令/元程序和 native_decide。编译在禁网、只读、低权限、资源受限 Docker 容器中运行，挂载仅包含生成的单个 Proof.lean；固定导入 Std 或固定 Mathlib 环境，末尾强制 #print axioms scienceGoal。

只有真实 Lean 返回 0、目标存在且公理依赖属于批准集合（propext / Classical.choice / Quot.sound，或空集）才记录 kernel_passed。记录命题/证明/环境哈希、编译版本、镜像 ID、诊断和公理列表。不支持的工具、超时、缺镜像、解析不出目标公理输出均不通过。检查成功相对工具链与所列公理成立，不验证自然语言翻译是否忠实。

报告若显式标记含形式化证明，或正文声称 formal proof / 形式化证明，须同时满足当前候选内核接受、陈述仍等于冻结快照、用户显式确认语义一致。即使关闭两模型门槛也不能跳过此要求。解除冻结或修改证明使先前验证无效。AI 可据真实 Lean 诊断生成下一候选；没有内核反馈不能冒称证明成功。
